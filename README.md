# ИИ-помощник по складскому учёту и планированию закупок спа-оператора (MVP)

Демонстрационный модуль интеллектуальной обработки складских данных для SPA-оператора Mountain & Sea Spa.

## Архитектура решения
- **Часть 1 (`part1_normalization.py`)**: Regex/NLP парсинг неструктурированных строк. Даты приводятся к ISO, объемы конвертируются в базовые единицы (л, кг, пар, шт) согласно справочнику.
- **Часть 2 (`part2_forecast.py`)**: Детерминированный расчет без LLM. Используется скользящее среднее с учетом линейного тренда. Выбросы анализируются: устойчивый рост считается новым уровнем спроса, единичные пики сглаживаются.
- **Часть 3 (`part3_qa.py` + `llm_client.py`)**: Гибридный подход. GigaChat определяет интент и сущности. Fallback (keyword matching) страхует систему при недоступности API. **Важно:** LLM не считает цифры. Все числовые ответы генерируются строго через вызов детерминированной функции из Части 2.

## Установка и запуск

1. Убедитесь, что установлен Python 3.11+.
2. Установите зависимости:
   pip install -r requirements.txt
3. Для подключения LLM создайте файл .env в корне проекта.

## Пример рабочего файла

# Провайдер языковой модели
Возможные значения:
gigachat - использовать GigaChat
fallback - использовать локальный разбор без LLM
LLM_PROVIDER=gigachat

# Ключ авторизации GigaChat
Значение можно получить в личном кабинете / у администратора доступа
GIGACHAT_CREDENTIALS=your_gigachat_credentials_here

## Scope для авторизации в GigaChat
# Для личного кабинета обычно используется:
GIGACHAT_API_PERS
# Для корпоративного кабинета:
GIGACHAT_API_CORP
# Пример
GIGACHAT_SCOPE=GIGACHAT_API_PERS

#№ Используемая модель
# Если указанная модель недоступна, попробуйте одну из:
GigaChat-Lite
GigaChat-Pro
GigaChat-3-Ultra
LLM_MODEL=GigaChat-Pro

# Температура генерации
Для извлечения сущностей рекомендуется 0.0
LLM_TEMPERATURE=0.0

# Проверка SSL
Если вы находитесь в корпоративной сети с самоподписанным сертификатом, временно отключите проверку SSL:
GIGACHAT_VERIFY_SSL=false

# Режим отладки LLM
true - печатать диагностические сообщения
false - работать без диагностического вывода
LLM_DEBUG=false

## Запуск пайплайна
Для запуска полного пайплайна используйте команду:
python main.py --dataset dataset.json --catalog catalog.json

## Запуск тестов
Для запуска тестов:
pytest tests/

## Результаты работы
Подробные результаты пайплайна, таблицы по всем частям, описание выбранных подходов и разбор граничных случаев находятся в файле RESULTS.MD
